# URL → Markdown 변환기

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 뽑아 보여 주고, 복사·다운로드하거나 프롬프트를 붙여 ChatGPT·Claude 새 대화로 바로 넘길 수 있는 서비스.

## Linked sources

- [prototype.html](prototype.html) — 승인된 화면입니다. 화면 구성, 요소 순서, 상태별 모습(빈 상태·로딩·결과·잘림 안내·오류), 문구, 좁은 화면 배치를 여기서 따릅니다. 더미 데이터와 가짜 동작(새 탭을 열지 않는 LLM 버튼, 주소 패턴으로 정해지는 결과, 6,000자 한도)은 참고용일 뿐 제품 동작이 아닙니다.
- [docs/decisions/ui-composition.md](../../decisions/ui-composition.md) — 화면 구성, component 선택, semantic token, 상태(loading·empty·error·disabled) 표현을 이 계약에 따릅니다.
- [docs/decisions/dependency-versions.md](../../decisions/dependency-versions.md) — `defuddle`과 DOM 구현 패키지를 추가할 때 버전 범위를 이 계약에 따릅니다.
- defuddle 문서: https://defuddle.md/docs

## User-visible outcomes

1. 사용자가 URL을 붙여넣고 변환하면 페이지 제목·저자 헤더와 렌더링된 본문 Markdown을 봅니다.
2. 결과를 클립보드로 복사하거나 `.md` 파일로 받습니다.
3. 프리셋 또는 직접 입력한 프롬프트를 선택적으로 앞에 붙여 ChatGPT 또는 Claude 새 대화를 엽니다.
4. 라이트/다크 모드를 전환합니다.

## Scope

### 입력
- URL 입력창 하나와 [변환] 버튼, [지우기] 버튼.
- [지우기]는 입력값, 결과, 프롬프트 선택, 오류 메시지를 모두 초기 상태로 되돌립니다.
- 입력값이 `http://` 또는 `https://` URL이 아니면 변환하지 않고 입력창 아래에 오류를 보여 줍니다.
- 변환 중에는 [변환] 버튼이 비활성화되고 로딩 상태를 보여 줍니다.

### 변환
- 페이지는 서버에서 가져오고, 본문 추출과 Markdown 변환은 `defuddle` npm 패키지로 합니다(필수).
- 상대 링크와 이미지 경로는 원래 페이지 기준의 절대 URL로 바뀝니다.
- 가져오기 실패(네트워크 오류, 4xx/5xx, HTML이 아닌 응답)와 본문 추출 실패(결과가 비어 있음), 차단된 주소는 서로 다른 오류 메시지로 구분해 입력창 아래 경고 상자에 보여 줍니다. 오류가 떠 있는 동안 결과 영역은 숨깁니다.
- 변환 중에는 결과 자리에 로딩 스켈레톤을 보여 줍니다. 아직 변환하지 않았을 때는 결과 자리에 빈 상태 안내를 보여 줍니다.

### 결과 확인
- 헤더: 페이지 제목. 저자가 있으면 저자, 없으면 원본 도메인을 함께 보여 주고, 원본 URL로 가는 링크를 둡니다.
- 본문: Markdown을 렌더링해서 보여 줍니다(제목, 목록, 링크, 코드블록, 표, 이미지).
- 내보내기와 LLM 열기 control은 결과가 있을 때만 활성화됩니다.

### 프롬프트
- 프리셋: "요약해줘", "한국어로 번역해줘", "쉽게 설명해줘", 그리고 "직접 입력".
- 기본값은 프롬프트 없음이며, 한 번에 하나만 선택합니다. 다시 누르면 선택이 해제됩니다.
- "직접 입력"을 선택하면 텍스트 입력창이 나타납니다. 입력값은 저장하지 않으며 새로고침하거나 [지우기]를 누르면 사라집니다.
- 선택된 프롬프트는 본문 앞에 붙고, 프롬프트와 본문 사이는 빈 줄 하나로 구분합니다.

### 내보내기
- **복사하기**: 프롬프트가 선택되어 있으면 프롬프트+본문, 없으면 본문을 클립보드에 넣고 성공 피드백을 보여 줍니다.
- **.md 다운로드**: 제목 헤더와 본문 Markdown만 담은 파일을 받습니다. 프롬프트는 넣지 않습니다. 파일명은 페이지 제목에서 파일명에 쓸 수 없는 문자를 뺀 값이고, 제목이 없으면 도메인을 씁니다.
- **ChatGPT로 열기 / Claude로 열기**: 프롬프트(선택 시)와 본문을 새 대화 입력에 미리 채운 상태로 새 탭에서 엽니다.
  - 전체 텍스트가 해당 서비스의 주소 길이 한도 안이면 그대로 넘깁니다.
  - 한도를 넘으면 프롬프트는 온전히 두고 본문 뒤쪽을 잘라 한도에 맞춘 뒤 넘깁니다. 잘린 본문 끝에는 내용이 잘렸다는 표시를 붙여 LLM도 일부만 받았음을 알게 합니다.
  - 잘렸을 때는 화면에 "본문이 길어 일부만 전달됐어요. 전체가 필요하면 복사하기를 쓰세요" 취지의 안내를 보여 줍니다.

### 기타
- 다크모드 토글: 처음에는 시스템 설정을 따르고, 사용자가 전환하면 그 선택을 다음 방문에도 유지합니다.

## Acceptance criteria

1. 정상적인 기사 페이지 URL을 변환하면 제목과 저자(또는 도메인) 헤더 아래에 본문이 렌더링되고, 내비게이션·푸터 같은 주변 요소는 나오지 않는다.
2. 원본 페이지의 상대 링크가 결과에서 원본 도메인 기준 절대 URL로 열린다.
3. `ftp://x`, `abc`, 빈 값으로 변환하면 요청 없이 입력 오류가 보인다.
4. 존재하지 않는 도메인, 404 페이지, 이미지 URL은 "가져오기 실패" 오류를, 본문이 없는 HTML은 "본문을 찾지 못함" 오류를 보여 준다.
5. `http://localhost`, `http://127.0.0.1`, `http://10.x.x.x`, `http://192.168.x.x`, `http://169.254.169.254` 및 이런 주소로 리다이렉트되는 URL은 서버가 가져오지 않고 오류를 돌려준다.
6. [지우기]를 누르면 입력, 결과, 프롬프트 선택, 직접 입력값, 오류가 모두 비워진다.
7. 프롬프트 없이 복사하면 클립보드에 본문만, "요약해줘"를 선택하고 복사하면 `요약해줘` + 빈 줄 + 본문이 들어간다.
8. 다운로드한 `.md` 파일에는 프롬프트가 없고, 파일명이 페이지 제목 기반이다.
9. 짧은 글에서 Claude로 열기·ChatGPT로 열기를 누르면 새 탭의 새 대화 입력에 프롬프트+본문 전체가 채워져 있고, 잘림 안내가 나오지 않는다.
10. 한도를 넘는 긴 글에서 같은 버튼을 누르면 새 대화 입력에 프롬프트 전체와 잘린 본문, 끝의 잘림 표시가 채워지고, 화면에 잘림 안내가 보인다.
11. "직접 입력"을 선택하면 입력창이 나타나고, 그 값이 복사·LLM 열기에 쓰인다. 새로고침하면 값이 남아 있지 않다.
12. 다크모드로 전환하고 새로고침해도 다크모드가 유지된다.
13. 결과가 없을 때 복사·다운로드·LLM 열기 control은 비활성화되어 있다.

## Settled constraints

- **본문 추출은 `defuddle` 라이브러리로 합니다.** 사용자가 필수로 지정했습니다. Node에서는 `defuddle/node`와 DOM 구현(linkedom 또는 jsdom)을 씁니다. 호스티드 `defuddle.md` API는 쓰지 않습니다. 외부 서비스 의존과 요청 한도가 생기기 때문입니다.
- **페이지 가져오기는 서버에서 합니다.** 브라우저에서는 CORS 때문에 임의의 페이지를 가져올 수 없습니다.
- **화면은 한 컬럼입니다**(프로토타입 승인). 위에서부터 헤더(다크모드 토글) → URL 입력 → 오류 안내 → 프롬프트 → 내보내기 action과 잘림 안내 → 결과 카드 순서입니다. 좁은 화면에서도 이 순서를 유지한 채 쌓습니다. 내보내기 버튼 네 개는 프롬프트 바로 아래, 결과 카드 위에 한 줄로 둡니다(배치 비교 후 확정). 결과 카드 헤더 안의 툴바는 프롬프트와 버튼이 떨어져 있어서, 하단 고정 바는 본문을 늘 가리고 모바일에서 화면을 많이 차지해서 쓰지 않았습니다.
- **LLM 열기가 한도를 넘으면 본문을 잘라 넘기고 잘렸다고 알립니다**(사용자 결정). 다른 선택지였던 "클립보드 복사 후 빈 대화 열기"와 "버튼 비활성화"는 쓰지 않습니다. 한 번에 바로 열리는 흐름을 우선했고, 내용이 조용히 빠지는 문제는 화면 안내와 본문 끝 잘림 표시로 드러냅니다.

## Assumptions

- 서버는 받은 HTML만 파싱하고 JavaScript를 실행하지 않습니다. 그래서 클라이언트 렌더링 전용 페이지(SPA)는 본문 추출 실패로 처리합니다.
- 잘림 표시는 본문 끝의 한 줄 문구(예: `…(이하 생략: 원문이 길어 일부만 포함됨)`)입니다.
- 주소 한도는 서비스별 상수로 둡니다. 실제 값은 구현 시 각 서비스에서 확인합니다.
- 다크모드 선택은 브라우저 로컬 저장소에 보관합니다.

## Off-limits

- 변환 기록 저장, 계정, 로그인. 요청에 없고 "1회용·저장하지 않음" 방향과 맞지 않습니다.
- 프롬프트 프리셋 편집이나 직접 입력값 저장. 사용자가 직접 입력을 1회용으로 지정했습니다.
- JavaScript를 실행하는 헤드리스 브라우저 렌더링. 범위와 운영 비용이 커집니다.

## Deferred points

- **공개 배포 시 남용 방지(요청 속도 제한 등)** — 서버가 임의 URL을 대신 가져오므로 공개 배포하면 필요할 수 있습니다. 현재 배포 계획이 정해지지 않았습니다. 공개 URL로 배포하기로 결정하는 시점에 다시 엽니다. 그때까지는 SSRF 차단만 둡니다(interim).

## Remaining risks

- **주소 길이 한도가 확인되지 않았습니다.** `chatgpt.com/?q=`와 `claude.ai/new?q=`의 실제 허용 길이와 동작을 로그인 상태에서 검증하지 못했습니다. 한도를 너무 크게 잡으면 열리지 않거나 서비스 쪽에서 잘리고, 너무 작게 잡으면 불필요하게 잘립니다. 두 서비스가 `?q=` 미리 채우기를 바꾸거나 없애면 이 기능이 깨집니다.
- **Next.js 번들링과의 호환성**: `defuddle/node`는 ESM이고 문서는 `"type": "module"`을 요구합니다. 이 프로젝트의 서버 런타임에서 그대로 import되는지는 별도 scratch 실험(Node 24 + linkedom)에서만 확인했습니다.
- 사이트에 따라 봇 차단, 로그인 벽, 페이월 때문에 가져오기나 추출에 실패할 수 있습니다.
