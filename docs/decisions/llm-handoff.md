# LLM으로 넘기기

## Decisions

- ChatGPT·Claude로 열기는 각 서비스의 새 대화 주소에 프롬프트와 본문을 `?q=`로 미리 채워 새 탭에서 엽니다.
- 주소 길이 한도는 서비스별 상수로 둡니다.
- 한도를 넘으면 프롬프트는 온전히 두고 본문 뒤쪽을 잘라 한도에 맞춥니다. 잘린 본문 끝에는 잘림 표시를 붙이고, 화면에는 일부만 전달됐다는 안내와 함께 복사하기를 쓰라는 안내를 보여 줍니다.

## Why

사용자는 긴 글에서도 한 번에 바로 열리는 흐름을 우선했습니다. 내용이 조용히 빠지는 문제는 화면 안내와 본문 끝 표시로 드러내, 사용자와 LLM이 모두 일부만 전달됐다는 것을 알 수 있게 했습니다.

## Reconsider when

- 두 서비스가 `?q=` 미리 채우기를 바꾸거나 없앨 때
- 실제 한도가 확인되어, 한도 안에서 대부분의 글이 잘리지 않는다는 전제가 깨질 때. 현재 한도는 검증되지 않았습니다([follow-up](../follow-ups/url-to-markdown.md)).

## Still-rejected alternatives

- 한도를 넘으면 전체를 클립보드에 복사하고 빈 새 대화를 여는 방식 — 사용자가 직접 붙여넣어야 해서 한 번에 열리는 흐름이 깨집니다.
- 긴 글에서 LLM 열기 버튼을 비활성화하는 방식 — 가장 필요할 때 기능을 막습니다.
