# 내보내기 action

## Decisions

- 내보내기 버튼(복사하기, .md 다운로드, ChatGPT로 열기, Claude로 열기)은 프롬프트 선택 바로 아래, 결과 카드 위에 한 줄로 둡니다. 좁은 화면에서는 같은 자리에서 줄바꿈해 쌓습니다.
- 복사하기와 LLM 열기에는 선택된 프롬프트를 본문 앞에 붙입니다. .md 다운로드에는 프롬프트를 넣지 않습니다.
- 결과가 없을 때 내보내기 버튼은 비활성화합니다.

## Why

"프롬프트 고르기 → 내보내기"가 위에서 아래로 바로 이어져야 프롬프트가 어떤 action에 적용되는지 분명합니다. 세 가지 배치를 같은 상황(긴 글, 프롬프트 선택, 잘림 안내)에서 비교한 뒤 사용자가 이 배치를 골랐습니다. 다운로드한 파일은 원문 보관용이어서 일회성 프롬프트를 섞지 않습니다.

## Reconsider when

- 내보내기 대상이 늘어 한 줄 배치가 넓은 화면에서도 두 줄 이상으로 넘칠 때

## Still-rejected alternatives

- 결과 카드 헤더 안의 툴바 — 프롬프트(카드 위)와 버튼(카드 안)이 떨어지고, 스크롤하면 버튼이 사라지는 문제는 그대로입니다.
- 화면 하단 고정 바(프롬프트와 LLM 열기를 모음) — 본문을 늘 가리고, 잘림 안내가 뜨면 모바일 화면의 약 1/3을 차지합니다.
