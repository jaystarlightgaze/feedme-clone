# url-to-markdown 후속 확인

## LLM `?q=` 주소 길이 한도 미검증

- `lib/llm-link.ts`의 `LLM_SERVICES`가 chatgpt.com, claude.ai 모두 인코딩된 전체 주소 8,000자로 잘라 넘긴다.
- 근거: 두 서비스의 실제 한도는 공식 문서에 없고 로그인 상태로 확인하지 못했다. 일반 웹 서버/CDN 요청 줄 한도(약 8KB)보다 낮게 잡은 보수적 값이다.
- 영향: 한글은 인코딩하면 글자당 9자라 한글 본문은 약 800자만 전달된다. 실제 한도가 더 크면 불필요하게 잘린다.
- 다음 단계: 로그인한 브라우저에서 긴 `?q=`를 직접 열어 동작하는 최대 길이를 확인한 뒤 상수만 조정한다.

## SSRF: DNS 재바인딩 틈

- `lib/convert/convert-url.ts`는 DNS 조회로 주소를 검사한 뒤 `fetch`가 다시 이름을 해석한다. 두 조회 사이에 응답이 바뀌는 재바인딩 공격은 막지 못한다.
- 스펙 범위(사설망·로컬·링크로컬과 리다이렉트 차단) 밖이라 고치지 않았다. 공개 배포를 결정할 때 연결 시점에 IP를 고정하는 방식으로 다시 검토한다.
